# Medicinal plant research dataset v0.3 (EXPERIMENTAL)

627 visually screened, community-labeled photos across10species. This is a versioned research snapshot, NOT an expert-certified final dataset, medical identification resource, or the Phase I report dataset. No performance claim or endorsement from photographers/platforms.

Includes421train,85validation,56already-usedpilot-test and65already-readinternal-new-test photos. Both tests are now development history, not untouched final benchmarks.95additions entered train only; no holdout labels changed. A genuinely external phone-photo benchmark is still needed.

Media retain per-photo CC0,CC-BY4.0 orCC-BY-SA4.0 terms. See ATTRIBUTION.csv and manifest.json for authors, original source URLs, observationIDs,licenseURLs and hashes. Do not apply the code license to photos. No pixel edits were made to the downloaded medium-resolution source copies. If modifying CC-BY-SA images, follow ShareAlike. This collection does not claim to clear privacy, publicity or other non-copyright rights.

Sources: Pl@ntNet exact-species public leaf galleries, with community-vote filters; iNaturalist research-grade observations for selected Bacopa/Tulsi/Bael/Catnip photos. Visual review is leaf-content screening only, not expert label confirmation. Contributor grouping/exact+conservative perceptual checks reduce leakage, not a guarantee. Do not consume plants based on this dataset or model predictions.
